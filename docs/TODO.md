# next

- [ ] Окно настроек дорастает до редактора конфига. Сегодня в нём три тумблера фич, а команды `load_settings`/`save_settings` уже отдают обе картины конфига (`file` и `effective`) и пишут файл патчем — то есть машинерия под форму готова, недостаёт самой формы. План на неё расписан целиком в `docs/superpowers/plans/2026-08-14-settings-window.md`, задача 6: четыре группы и одиннадцать оставшихся полей (`sshHost`, `remoteDir`, `windowHost`, `terminals`, `tickMs`, `dumpCacheMs` и блок `mqtt:`), значение из `file`, подсказка `in effect:` из `effective`, патч только из тронутого, пустое поле пароля в патч не попадает вовсе. Группа MQTT помечается «takes effect after restart»: поток подписки поднят на старте и останавливаться не умеет. Блок `state:` в форму не входит намеренно — слияние патча сохранит его нетронутым и без редактора.
